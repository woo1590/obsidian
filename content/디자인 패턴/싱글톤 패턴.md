하나의 인스턴스를 생성하여 지속적으로 사용하도록 만드는 패턴
사용이 쉽고 편리하지만 객체지향의 철학을 무시한다는 의견도 있음 


```cpp
clss Singleton
{
private:
	Singleton(){}
	~Singleton(){}
	Singleton(const Singleton& _ref) = delete;
	Singleton& operator=(Singleton& _ref) = delete;
public:
	static Singleton& getInstance()
	{
		static Singleton Instance;
		return Instance;
	}
}
```
- 하나의 인스턴스만 존재해야 하기 때문에 복사 생성자와 대입 연산자 오버로딩을 삭제
- getInstance 함수를 통해 인스턴스에 접근
