### Dx에서의 화면 출력 방식
 - api에서는 더블 버퍼링을 사용하여 화면을 출력
 - dx에서는 스왑체인 방식을 사용하여 화면을 출력
```cpp
Render_Begin() 
//백버퍼에 실제 그리기 시작
//1. 지우기
//2. 픽셀 값 채울 것을 명령
Render_End()  
//그려진 결과물을 화면으로 송신
//1. 픽셀 값 채우기 종료
//2. 전면 버퍼와 서피스 교환

discard -> 스왑체인 방식
flip -> 하나의 버퍼를 번갈아 사용
copy -> 더블 버퍼링과 비슷한 방식
```

### Dx의 버퍼 종류
- 타겟 버퍼
- 스텐실 버퍼(그림자, 반사 등을 표현하기 위한 버퍼)
- z-depth 버퍼(z 값 기준으로 정렬하여 그리기 위한 버퍼)
