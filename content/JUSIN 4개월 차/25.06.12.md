# 알파 렌더링 기법 정리

## 알파 블렌딩 (Alpha Blending)

- 두 개의 픽셀 색상과 알파값을 섞어서 최종 색상을 만듦
- 기본 블렌딩 공식:  
  `최종색 = SrcColor * SrcAlpha + DestColor * (1 - SrcAlpha)`
- **용도:** 반투명, 유리, 연기, 파티클, 물 등
- 장점:
  - 자연스러운 투명 효과
  - 부드러운 경계 표현
- 단점:
  - Z버퍼 Write 사용 불가 → 소팅 필요
  - 픽셀당 연산 부담 큼 → 성능 저하 발생
  - GPU 병렬 처리 비효율적 (read-modify-write 문제)
- **소팅 필수 (뒤에서 앞으로)**

## 알파 테스트 (Alpha Test)

- 픽셀의 알파값을 임계값과 비교하여 출력 여부 결정
- 비교식 예시:  
  `if (Alpha >= Threshold) 출력, else 버림`
- **용도:** 나뭇잎, 철망, 머리카락, 경계가 뚜렷한 오브젝트
- 장점:
  - 성능 부담 적음 (Z버퍼 Write 사용 가능)
  - 소팅 불필요
- 단점:
  - 부드러운 투명 효과 불가능
  - 경계선이 날카로움 (Alias 현상)
- **MSAA와 조합 시 경계 보완 가능**

---

## 알파 소팅 (Alpha Sorting)

- 알파 블렌딩의 부작용 해결을 위한 거리 정렬
- 카메라에서 먼 순서대로 정렬 후 렌더링
- 일반 렌더링 순서:
  1. 불투명 → Z버퍼 Write ON → 먼저 렌더링
  2. 투명 → Z버퍼 Write OFF → 거리 소팅 → 블렌딩 렌더링
- 장점:
  - 블렌딩 정확도 확보
- 단점:
  - 소팅 오류 가능 (겹침, 교차, 트랜스페런시 아티팩트 발생)
  - 복잡한 소팅 로직 필요

## 요약 비교표

| 기법 | 장점 | 단점 | 주 용도 |
|--|--|--|--|
| 알파 블렌딩 | 자연스러운 투명 | 소팅 필요, 성능 저하 | 유리, 연기, 물, 파티클 |
| 알파 테스트 | 빠르고 가벼움 | 경계 날카로움 | 나뭇잎, 철망, 머리카락 |
| 알파 소팅 | 블렌딩 정확성 확보 | 소팅 오류 가능 | 대부분 투명 오브젝트 |

---

## 일반적인 엔진 렌더링 순서

1. **Opaque Pass (불투명 렌더링)**
   - Z버퍼 Write ON
   - 알파 테스트 적용 (있을 경우)

2. **Transparent Pass (투명 렌더링)**
   - Z버퍼 Write OFF, Read ON
   - 거리 소팅 후 알파 블렌딩 적용
