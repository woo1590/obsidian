
### 컴포넌트
- 상속의 한계점
  1. 규모가 커지고 기능이 많아질수록 부모 클래스가 여러가지 기능을 소유하게 됨
  2. 특정 오브젝트에만 필요한 기능이 다른 자식 클래스도 소유하는 문제

- 특정 기능들을 만들어 놓고 각 오브젝트들이 필요한 기능을 소유하는 방식

### Dynamic Component vs Static Component
- Dynamic Component - 매 프레임 업데이트가 필요한 컴포넌트
  Transform, Collision
  
- Static Component - 매 프레임 업데이트가 필요하지 않은 컴포넌트
  Mesh, Material, Render

### VertexBuffer
- 정적 버퍼 - Managed
  비디오 메모리(gpu메모리)에 올라가지 못하는 나머지 요소들을 ram에 백업
  상대적으로 안전하지만 두 개의 메모리를 사용하기 때문에 속도가 느리다

- 동적 버퍼 - Default
  비디오 메모리에 모든 데이트를 저장
  정적 버퍼에 비해서 속도가 빠르다
