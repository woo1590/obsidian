if문

```
if(조건){
	실행할 코드
}
else if(조건){
	실행할 코드
}
else{
	실행할 코드
}
```
*if 문 단독으로 사용시에는 break를 사용 할 수 없다*


switch 문 : 상수 조건 분기문
```
switch(정수 값){
	
	case 값:
		
		실행코드
		break; //break를 만난 시점에서 switch문을 벗어남
		
	case 값:
		
		실행코드
		break;
		
	case 값:
		
		실행코드
		break;
		
	default:  //정해진 값이 아닌 다른 값이 들어왔을 때의 예외처리
		실행코드
		
}
```


*switch문 안에서 변수를 선언하려면 각각의 case를 중괄호를 통해 묶어줘야한다.*
```
switch(정수 값){
	
	case 값:
		{
		실행코드
		}
		break; //break를 만난 시점에서 switch문을 벗어남
		
	case 값:
		{
		실행코드
		}
		break;
		
	case 값:
		{
		실행코드
		}
		break;
		
	default:  //정해진 값이 아닌 다른 값이 들어왔을 때의 예외처리
		실행코드
		
}
```
