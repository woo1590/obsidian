
### 이미지 출력

- 지금 당장은 BMP 파일을 사용하여 이미지 출력
- 현시대에서는 png파일을 주로 사용함(알파 채널의 유무)

### BmpManager
- 싱글톤 클래스
- map컨터이너를 통해 파일 저장
  (key : 이미지 이름(문자열) value : bmp클래스 포인터)
- 문자열은 상수 주소값으로 저장되기 때문에 문자열 비교 함수를 만들어줘야 함(함수 객체든, 연산자 오버로딩이든)

```cpp
Render(HDC hdc)
{
	HDC hMemDC = 비트맵 매니저에서 value 가져와야 함 

	BitBlt(hdc,  //복사 받는 dc
	 tRect.left,
	 tRect.top,
	 tRect.right,
	 tRect.bottom,
	 hMemDC,      //복사 할 dc
	 0, 0,        //복사하 이미지의 비트맵 시작 좌표
	 SRCCOPY);    //그대로 복사하여 출력
}
```
-----

### 색상을 지우는 함수
- 이미지를 그대로 사용하게 되면 주변 배경까지 같이 출력되게 됨
- 주변 배경 색을 지워서 최대한 이미지만 출력
  (완벽하게 모든 색을 지우지는 못함)

-----
### 더블 버퍼링
- 그리기와 그리기 사이의 깜빡거림을 줄이기 위한 기법
- dc에 바로 그리는 것이 아닌 dc와 같은 크기의 이미지에 그림을 그리고 이전 프레임의 화면을 덮어 그리는 방식[^1]

### 만약 컴포넌트 방식이면?

object component에 bmpComponent를 추가하고 해당하는 이미지를 bmpManager에서 가져옴
