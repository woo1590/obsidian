
**Left
- 가장 왼쪽 x좌표
**Top
- 가장 위 y좌표
**Right
- 가장 오른쪽 x좌표
**Bottom
- 가장 아래 y좌표

Left-Top, Right-Bottom 은 기본적으로 외워놓으면 좋음

----
### HDC
- Handle Device Context
- Devic Context란 출력에 필요한 정보를 가지는 데이터 구조체
- 좌표, 색 ,굵기 등 출력에 필요한 정보를 모두 가지고 있다
- HDC란 DC의 정보를 저장하는 구조체에 접근하기 위한 핸들

----
### MovetoEX(HDC hdc ,int x, int y, LPPOINT lppt)
- 해당 x,y좌표로 커서를 이동

### LineTo(HDC hdc, int x, int y)
- 커서부터 해당 x,y좌표까지 직선을 그리는 함수

### Rectangle(HDC hdc, int left, int top, int right, int bottom)
- 각 점들을 꼭짓점으로 하는 사각형을 그리는 함수

### Ellipse(HDC hdc, int left, int top, int right, int bottom)
- 각 점을 꼭짓점으로 하는 사각형에 내접하는 원을 그리는 함수
