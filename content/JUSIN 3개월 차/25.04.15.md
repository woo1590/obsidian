### 원 충돌
- 중점과 중점사이의 거리를 구해서 
  (r1+r2)>distance 일 경우 충돌 판정

```cpp
bool checkCircle(CObj* _pDst, CObj* _pSrc)
{
	float fWidth = abs(pDst->getInfo()->fX 
	- pSrc->getInfo()->fX);
	float fHeight = abs(pDst->getInfo()->fY 
	- pSrc->getInfo()->fY);
	float fDiagonal = sqrtf(fWidth*fWidth 
	+ fHeight*fHeight);

	float fRadius = (_pDst->getInfo()->fX 
	+ _pSrc->getInfo()->fX)*0.5f;

	return (fRadius > fDiagonal);
}
```
