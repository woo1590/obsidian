### 맵 에디터
- LineManager의 멤버변수로 POINT(점)을 저장할 수 있는 벡터를 선언
- Update함수에서 마우스의 위치를 가져오고 
  첫 번째 클릭 -> left point, 두 번째 클릭 -> right point, 이후 벡터에 저장
- 스크롤을 통해 맵을 이동시키며 전체적인 맵 그리기

### 카메라
- 현재 뷰파인더에 있는 부분만 출력 (맵이 굉장히 방대하기 때문)

### 스크롤
- 프레임은 고정 되어 있음
- 전체 맵(배경)이 움직이면서 보여지는 부분을 전환
- 그리기 시점에 적용
- 스크롤의 범위는 음의 범위 ~ 0


### WinAPI의 파일 입출력
```cpp
HANDLE hFile = CreateFile(L"../Data/Line.dat",	//파일의 경로
							GENERIC_WRITE,		
			//파일 접근모드(GENERIC_WRITE : 쓰기 모드 GENERIC_READ : 읽기 모드)
							NULL,				
							NULL,
							CREATE_ALWAYS,		
	//생성 방식(CREATE_ALWAYS : 파일이 없으면 생성, 있으면 덮어쓰기 OPEN_EXISTING : 파일이 있을 경우에만 불러오기)
							FILE_ATTRIBUTE_NORMAL,
							NULL)
```
